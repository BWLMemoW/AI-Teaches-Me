# 先配置你的 AI

> 内置示例讲义（随包分发，离线可读）。对应知识点：`kp-seed-001` / `kp-seed-002` / `kp-seed-003`。

**先别急着学知识——先让这个应用会说话。** 这一节只做一件事：把 AI 接上，然后看着它开口。

## 直觉：一切都发生在你自己的工作区

ATM 不把课程藏在云里。`Courses/` 就是你的全部课程资产，`data/` 里放配置、索引与日志。**升级程序不影响课程内容，删掉索引也能自动重建。**

### 三步接上 AI

1. 打开左侧「设置」，填写 **Base URL** 与 **API Key**（默认档案是 DeepSeek，自带读图能力）；
2. 点「测试连接」，看握手耗时与可用模型列表；
3. 随便问一句，看到文字**一个字一个字冒出来**，就说明流式对话已经跑通。

| 你想改的东西 | 去哪里改 | 会发生什么 |
| --- | --- | --- |
| 供应商 / 密钥 | 设置 → AI 供应商 | 只改配置，不动任何课程数据 |
| 配色与字体 | 设置 → 外观 | 四套主题即时生效，阅读区一起跟随 |
| 讲解风格 | 设置 → 教学风格 | 只改表达层，不改知识点与深度 |

```powershell
# 用系统 Python 直接启动（开发方式）
D:\Python\Python\python.exe -m app.main
```

### 一个小样例

只想确认「Key 有没有填对」？点「测试连接」。它会先请求 `/models` 握手，把耗时和模型列表给你；如果这个端点没有模型列表接口，它会明确说「握上了，但拿不到列表」，而不是含糊地报一句失败。

这就是本项目的一条原则：**错误必须可操作**——状态码 + 人话解释 + 下一步建议。

## 小结

- 课程与配置都在你的工作区，随时可备份、可迁移
- 密钥进系统凭据库，配置文件里只留引用名
- 测试连接 = 握手耗时 + 模型列表 + 可读的错误原因
