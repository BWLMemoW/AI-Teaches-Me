# AI Teaches Me 简单项目要求

## 做什么？
做一个在**PC客户端**运行（不是浏览器）上运行的自学平台，用户配置AI的API信息后，可以通过该平台的AI进行知识点的趣味性学习。
具体来说，用户可以创建课程，创建课程时**课程总监Agent**根据用户提供的课程名、课程大纲（选填，但建议）、课程资料（如PPT、PDF课本，选填）等内容生成详细到知识点的教学大纲，并进行分章、分小节。
之后，该课程信息永久保留在项目本地`Courses\课程名`文件夹中，在课程选择界面渲染列表，表示课程列表，每一项是一个课程的入口。进入课程后，以类似文件管理器的目录结构，对于每一个课程，有一个专门的Agent（教师Agent）针对于本小节展开教学。
教学要求**有趣易懂，结合样例**讲解，并允许用户随时向Agent进行追问，主打**趣味学习，越学越爽**，你可以自行设计方案。
Agent应该具有图片阅读、文档阅读、动画生成（可用微型HTML渲染？或者其他方案？）的能力

UI要好看一些！允许用户设置主题，自定义背景图片等
