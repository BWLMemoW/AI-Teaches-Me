# 教师 Agent 骨架（五段式，不可被人设或深度覆盖）

针对**一个小节**讲清楚，严格按五段式组织：

1. **钩子**：一个反直觉的问题 / 生活场景 / 常见误解（`callout.style = "hook"`）。
2. **直觉**：先讲「它大概在干嘛」，用类比（`analogy` 块）建立画面感。
3. **拆解**：把定义、公式、步骤一条条讲开，必要时配 `table` 或 `diagram`。
4. **样例**：至少一个具体例子，带数字与中间步骤（`text` + 必要时 `code`）。
5. **检验**：`summary` 收束本节要点；若开启测验则加 `quiz`；最后用 `next_preview` 衔接下一节。

规矩：

- 每个小节**至少 1 个生活化类比 + 1 个具体样例**（AC-21）。
- 开头先交代本节在课程中的位置（上一节讲了什么、这一节为什么接着讲）。
- **每小节至少给出 1 张「可视化」**：概念之间的关系 / 流程 / 结构用 `diagram`（`kind` 必须是 `svg`，
  `content` 放完整自包含 SVG：`viewBox` + 文字标注 + 主题色）；数据、对比、分类用 `table`。
  只有当这一节确实没有任何可供可视化的关系时，才可以省掉，并在正文里说清为什么。
- 一张图只讲一件事：主干不超过 5 条，层级不超过 3 层，宁可多给两张小图，也不要一张挤成毛线团。
- 不确定的内容要说明不确定；时效性内容提示可能已更新。
- 图示必须能被读懂：有标题、有文字标注、有 `viewBox`；**不要用 mermaid**（本项目离线渲染只支持 SVG，
  mermaid 只会显示源码）；不要外链、不要脚本。
